# Технический прогон до KV cache

Эти файлы не входят в основные результаты. Сначала был завершён continued-CE
seed 42 и прерван completion без KL после 250 updates. Затем sampling ускорен
KV cache, проверено равенство вероятностей, и все fine-tunes заново запущены
одним кодом с теми же seeds, loss, budgets и правилами выбора.

Часть этого validation уже была известна при изменении реализации. Reward
functions и hyperparameters после неё не менялись, test model metrics ещё не
вычислялись. В новой версии первые 200 validation updates совпадают с прежними
с точностью численных округлений. Это инженерная оптимизация, не дополнительный
вариант для поиска победителя. Основные результаты находятся только в main/.

Веса технического прогона остаются в локальной models/ и не упаковываются.
Его затраты не включены в сумму fit times основных моделей; эта сумма не
заявляется как полное время разработки/всего сеанса.
