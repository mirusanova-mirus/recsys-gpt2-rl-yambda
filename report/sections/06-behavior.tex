\subsection{Изменение поведения и коллапс}

Без KL прогноз дослушивания растёт с 0.6925 у SFT до 0.7346,
но NDCG@10 падает с 0.00688 до 0.00157.
Выдача смещается к более коротким трекам,
первый объект всё чаще совпадает у разных пользователей

Доля самого частого top-1 растёт с 1.6\% до 55.0\%,
энтропия снижается с 7.336 до 4.987.
При этом вероятность знакомого трека уменьшается с 44.4\% до 19.7\%.
Наблюдаемый коллапс проявляется в обезличивании выдачи,
усиления повторов из реальной истории нет

Более сильный KL сохраняет персонализацию ценой меньшего прироста награды.
Оптимизация seconds увеличивает ожидаемую длительность
до 204.1 секунды против 188.3 у SFT, но не повышает прогноз дослушивания.
Одинаковый \(\beta\) при разных шкалах награды не задаёт одинаковую
силу штрафа. Balanced дополнительно меняет несколько компонентов,
поэтому его результат не выделяет эффект каждого из них

Среди реальных test-целей 63.2\% треков уже встречались пользователю,
поэтому штраф за повторы может конфликтовать с релевантностью
по историческим данным. Расхождение RM и аудитора показывает
чувствительность оценки к предиктору,
но само по себе не доказывает использование ошибок RM

Вероятностная масса объектов без обучающих откликов основной RM
уменьшается с 7.90\% у SFT до 1.77\% без KL,
у balanced она равна 7.82\%.
Одновременно средний Jaccard для top-10 разных пользователей
растёт с 0.0035 до 0.3580 без KL.
Таким образом, списки сближаются, но сдвига к объектам без RM-меток нет.
Ошибка RM на новых действиях остаётся неизвестной
