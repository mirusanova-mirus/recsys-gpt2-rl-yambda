\section{Стоимость, надёжность и воспроизведение}

Среда: Python 3.9.6, Torch 2.5.1, Transformers 4.53.2, CatBoost 1.2.10; CPU, 4 threads на процесс. SFT grid и три итоговых seed: 75.2 минут чистого fit. Reward model fits: 0.9 минут; суммарный fit дообучений 57.8 минут. Это сумма измеренных fit times, без скачивания/подготовки/всей оценки и не оценка FLOPs.

Для RL отдельно записаны 96 000 sampled actions/run, optimizer updates, время и число CE positive targets. Для continued-CE число labels меньше, чем число RL actions: одинаковое число обновлений не даёт равный computational budget. Отдельный baseline замороженной SFT позволяет оценить, добавило ли обычное дообучение пользу.

Часть fits выполнялась параллельно и конкурировала за CPU; это не изолированный hardware benchmark. Для RL seed 43/44 отключён idle busy-wait OpenMP (\code{OMP_WAIT_POLICY=PASSIVE}, \code{KMP_BLOCKTIME=0}), при тех же четырёх вычислительных threads; runtime\_scheduling.json фиксирует различие. Суммарные fit times исключают прерванные инженерные прогоны и не равны всему времени разработки.

Аудит сравнил все 4,889,035 записей 1000 выбранных пользователей с исходным parquet, восстановил все 30,000 LM окон и проверил masking. Для всех cached states проверено history\_max \textless{} timestamp; по 256 примеров каждого split/kind точно восстановлены prefix, seen mask и labels. SHA источника и моделей проверены; saved test means пересчитаны из per-query CSV.

Восемь unit tests проверяют timestamp ties, causal replay и KV cache, masked labels, discount/leave-one-out baseline и направление градиента, OOV denominator, RM feature fractions и reward objectives. Tests не заменяют data audit. Упакованный архив содержит код, конфигурацию, планы, отчёт и компактные результаты; raw data, большие cache и обученные веса исключены.

Полное воспроизведение: создать Python 3.9+ environment, установить requirements.txt, выполнить make reproduce. Публичный parquet \textasciitilde{}426 MB скачивается по закреплённой revision и проверяется SHA. Рекомендуется около 10 GB свободного диска и 16--32 GB RAM; этот запуск выполнен на машине с 32 GB. Точное время зависит от CPU и библиотек. Команда demo печатает top-10 реального heldout prefix после обучения.

Cache reuse проверяет config, source и model hashes; при изменении дизайна нужно новое output\_dir. Текущие JSON содержат относительные пути внутри проекта. Reproduction сохраняет новый selection seal до test. Публикация или отправка работы не выполнялась.
