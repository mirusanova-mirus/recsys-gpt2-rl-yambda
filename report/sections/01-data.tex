\section{Данные и протокол}

Из \href{https://huggingface.co/datasets/yandex/yambda}{Yambda-50M}
равномерно выбраны 1\,000 из 9\,238 пользователей файла listens с seed 314.
Сохранены все 4\,889\,035 их прослушиваний, медианная длина истории
составляет 2\,752 события. Другие типы действий не использовались.
Органические прослушивания входят в контекст,
целями служат неорганические события

Время задано в секундах с округлением до 5 секунд.
Запрос соответствует пользователю и моменту целевого события.
Его история содержит только события со строго меньшим временем.
Неоднозначные цели с одинаковым временем исключены из функции потерь
GPT-2, при оценке такая группа задаёт множество релевантных ID

Последние три недели разделены на validation, confirmation и test,
все более ранние события отнесены к train. Во время оценки история
пополняется реальными событиями до текущего запроса, веса фиксированы.
Словарь содержит 16\,384 наиболее частых трека из train,
остальные ID преобразуются в UNK. Служебные PAD, BOS и UNK запрещены в выдаче

В test представлены 434 пользователя, у 931 запроса все цели вне словаря.
Общие Recall, NDCG и MAP учитывают все цели, вклад неизвестных ID равен нулю.
Ранжируется весь фиксированный словарь без выборки отрицательных объектов.
Для train-запросов требуется хотя бы одна известная цель, чтобы определить
дополнительную CE-потерю. На отложенных частях такого фильтра нет

Длительность и популярность оценены по train, эмбеддинги получены
из базовой GPT-2. Эти параметры доступны до validation,
но применяются к ранним train-префиксам ретроспективно.
До первого обучения размер словаря увеличен с 2\,048 до 16\,384
после проверки покрытия и замера на CPU. При этом проверялось
и покрытие отложенных ID, поэтому состав отложенных данных
был частично известен при проектировании эксперимента
