\subsection{Ожидаемая награда пяти stochastic шагов}

Отдельная дополнительная диагностика соответствует sampling temperature 1 при обучении. Начальные 256 запросов случайно выбраны из общего test sample без отбора по будущему продолжению сессии. На запрос и seed --- четыре траектории, пять шагов, \(\gamma=0.9\). В таблице нормированный return
\begin{equation}
\overline G_5=\frac{\sum_{t=0}^{4}\gamma^t r_t}{\sum_{t=0}^{4}\gamma^t};
\end{equation}
это шкала среднего completion, а не суммарные реальные минуты.

Для append-среды первичная разность balanced \ensuremath{-} continued-CE: +0.00620 [+0.00502; +0.00750]. Интервал по пользователям условен на этих моделях и четырёх общих MC draws. Его нельзя переносить на реальное поведение пользователей.

Под одним и тем же фиксированным набором весов проверяются append и frozen переходы. Различия показывают чувствительность surrogate return к модели контекстного перехода. Это не причинное сравнение пользовательских сценариев; обе динамики искусственные. Predicted return proxy на пяти шагах относится к перекрывающимся будущим окнам, поэтому его сумму нельзя интерпретировать как пять независимых возвращений.

Эта диагностическая оценка была добавлена после начала validation запусков, до test metrics; выбор моделей не использует её результаты. Основной EXPERIMENT\_PLAN.md сохранён, дополнение записано в DIAGNOSTIC\_PLAN.md. Checkpoints выбирались по first-step validation utility, хотя training return имеет horizon 5 --- дополнительное ограничение согласования train/selection objectives.
