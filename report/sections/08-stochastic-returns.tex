\subsection{Стохастические траектории}

Отдельная оценка использует температуру 1, как при обучении.
Начальные 256 запросов выбраны равномерно из test без отбора
по будущему продолжению. Для каждого запроса и seed сэмплируются
четыре траектории. Сравниваются добавление каждого ID в контекст (append)
и неизменный контекст (frozen). Общая метрика для всех политик равна
\[
  \overline G_5=\frac{\sum_{t=0}^{4}\gamma^t\widehat c_t}{\sum_{t=0}^{4}\gamma^t}
\]
Она сохраняет шкалу среднего прогноза дослушивания, \(\gamma=0.9\)
