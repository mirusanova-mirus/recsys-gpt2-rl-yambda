\section{Базовая GPT-2}

GPT2LMHeadModel обучена с нуля на последовательностях ID треков.
Эта базовая модель далее обозначается SFT.
По NDCG@10 на validation выбрана размерность скрытого представления 128
из вариантов 96 и 128. Итоговая модель содержит 2 слоя,
4 головы внимания и 2\,503\,424 параметра, контекст запроса ограничен
64 токенами. Матрица эмбеддингов общая для входа и выходной проекции

Для обучения выбраны 30\,000 перекрывающихся train-окон с шагом 32,
всего 645\,171 допустимая целевая позиция на эпоху.
Использованы AdamW со скоростью обучения 0.001, размер батча 32,
dropout 0.1 и ограничение нормы градиента до 1.
Лимит составляет 8 эпох, остановка выполняется после двух эпох
без улучшения validation NDCG@10. Функция потерь учитывает только
известные неорганические цели с однозначным временем,
органические события и UNK сохраняются в истории

Выбранная архитектура обучена с seed 42, 43 и 44.
Внутри каждого seed все варианты дообучения стартуют с одного SFT-чекпойнта.
Контроль continued-CE получает те же начальные префиксы и 300 обновлений.
Для множества известных целей \(P_t\) его функция потерь равна
\[
  \mathcal L_{\mathrm{CE}}=-\log\sum_{i\in P_t}\pi_\theta(i\mid s_t)
\]
При одной цели это обычная перекрёстная энтропия.
Число CE-меток меньше числа RL-действий, поэтому одинаковое число
обновлений не означает равный вычислительный бюджет
